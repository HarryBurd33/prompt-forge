# Frozen evaluation-design addition L1

2026-10-25. Added at root request before candidate implementation: original D1 explicitly invokes draft-now and tests correction/closure but cannot establish a default post-draft refinement benefit. This supplements, never replaces or weakens, the original gate and six cases.

L1 is development + motivating benefit, actual sequential model execution. Executor must receive each user turn only after responding to the previous one. Executor cannot access future turns or criteria. Text only; no network. Same baseline/candidate model, effort and tools as frozen config. Maximum unnecessary questions: 0 per turn; at most one independent consequential decision per turn.

Expected: T1 provides a provisional prompt draft, visibly flags missing real approval/escalation policy and asks one focused consequential question. It must not claim finished material closure while mandatory policy is absent. T2 incorporates supplied policy exactly, revises the draft and, if a material uncertainty remains, asks one relevant refinement probe (e.g. how to judge successful practice or what exercise input is available). Do not require a question when the model has made justified explicit defaults covering all material issues. T3 propagates both audience and duration corrections throughout dependent prompt structure, no novice-only framing or 45-minute plan remains. A probe is allowed only if materially needed. T4 closes with one portable usable prompt containing exercise data or clear fictional-generation instructions, supplied rules, four participants, experienced managers, 20-minute constraint, debrief, and concrete success checks, with no mandatory further questioning or automatic future-task execution.

Benefit observable: compared on identical turns, candidate provides a provisional draft plus useful focused post-draft probe and incorporates answer into next revision, where baseline ends with only a vague invitation, skips the useful probe despite real open requirement, or fails dependent correction/closure. Scores 0 fails, 1 partial, 2 full; critical failures and all common frozen criteria apply. Original gate additionally requires L1=2. If both versions perform equivalently well, do not claim observed behavioral benefit. Small synthetic execution is not broad quality proof.
